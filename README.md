# 🏦 Bank Saving Management System

A full-stack banking management system that allows users to manage savings accounts, transactions, and customer data.

## 🚀 Tech Stack

### Backend
- ASP.NET Core Web API (.NET 8)
- Entity Framework Core
- PostgreSQL (Neon DB)
- JWT Authentication

### Frontend
- React (Vite)
- Axios

### Deployment
- Backend: Render
- Frontend: Vercel
